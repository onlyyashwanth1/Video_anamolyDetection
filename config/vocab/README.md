# Generic concept vocabularies (unmodified public class lists)

- `kinetics700_actions.txt`: the 700 Kinetics-700 action classes, verbatim from MMAction2
  `tools/data/kinetics/label_map_k700.txt` (identical, line for line, to the list shipped
  with HVLMCLD-VAD as `K700_action_keywords.txt`).
- `coco80_objects.txt`: the 80 COCO detection classes, verbatim from the Ultralytics
  `cfg/datasets/coco.yaml` class map.

No entry is labelled normal or anomalous, and nothing was added, removed or reworded for any
benchmark. Which concepts count as unusual is decided per environment by its normal memory.
